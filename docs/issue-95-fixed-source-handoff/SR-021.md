## 3. Next 采用、排除与权威划分

| 对象 | 唯一权威/参考语义 | Next 采用与排除 |
|---|---|---|
| Task / Run | Go Host 拥有 ProductTask、模型交互和 Agent trajectory；Runtime 拥有 Run/RunEvent；一个 Task 可关零/多 Run | 采用“身份分离、显式 ref 关联”语义；**不复制** ProductTask v2、owner ledger、AgentInstance、HTTP `/api/v2` 或 v1 compatibility |
| Tool Catalog / 权限 | AgentInstance/MCP generation 初始化时 tools/list 并缓存；Provider 自有 Catalog，tool-mcp-gw 自有 Server Catalog；Runtime 解析 eligibility，Host 只能缩小 | 采用“发现/缓存不是授权”；Next 由唯一 Plugin Manager 发现/分发，Runtime 按 1.6.0 Artifact Binding/Scope 放行，**不采用** tool-mcp-gw/MCP 作为 Next 新组件 |
| Outcome / Reconcile | Runtime 拥有 authoritative Outcome、OUTCOME_UNKNOWN、Reconcile；Owner 提供业务事实/Receipt/Commit Proof；Host 不伪造 | 采用 Next F04/F05 同一分责；不把 Task completed、HTTP 成功或 Artifact 发布当 COMMITTED |
| ArtifactStore | Host 独有 reference issuance/resolution、access control、quota、lifecycle、publication；Runtime/Capability 授权与 Owner Outcome 留在原 Owner | **采用冻结 v1 wire 语义**作为 SR-010 参考，不直接复制 Go 代码；随机 opaque ref、Invocation/direction/slot、loopback channel、限额/过期、逐 Artifact SHA-256、原子发布保留。Next Python 实现仍 `NOT_IMPLEMENTED/NOT_RUN` |
| Planning | Planning V2 全套仍 vNext，ContextOffer/NEED_CONTEXT 不扩权 | 不迁移 Planning V2/GOAL_PLANNING；Next 只取必要 Context 来源、可见性和 Run 绑定 |
