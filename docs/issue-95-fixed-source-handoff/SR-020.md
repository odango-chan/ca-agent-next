## 3. 采用、排除、差异与缺失

| Next 域 | 采用/简化 | 排除及固定源差异 |
|---|---|---|
| F01 Host | 采用 `src/` 布局、组合入口、生产命令与 guarded examples 分离、精确 Run/Continuation 关联；`main.py` 的 `_EXAMPLES_AVAILABLE` 与测试中的持久 Run 恢复可作逐文件参考 | 不复制 `ca-agent-host`/`ca_agent_host`/`ca-plan`、5GC composition、Root Routing/Planning V2；Next 使用自身 Python Host/API 和 Skill-first |

| F04 Runtime | 采用统一调用边界的思想、dispatch 前 scope 拒绝、`OUTCOME_UNKNOWN` 不升级、`SUSPENDED` 恢复原 Run；`admitted_operation_allowlist`、`MutationOutcome`、`RuntimeResult` 为真实定位 | 源 `allowedResources.capabilities` 可解析为直接 Operation，属于旧 Callable/Operation 路径；Next 1.6.0 必须由 `capabilityBindings` 唯一解析内部 Callable，不能原样复用。无生产 Admission/Trust 扩散 |
