## 3. 原文、采用与差异

三份直接移交正文实际执行了 `git diff --no-index`，结果如下。它们不是逐字节副本，不能以“迁移”推断原文一致。

| 源→Next | numstat（增/删） | 实测差异与结论 |
|---|---:|---|
| toolchain → 工具链设计 | 53 / 19 | 增加中央元数据、固定源链接、§3.2.1 冻结 v1alpha5 与 Development profile 分界、1.6.0-only 消费边界及修订表；更新 v2.1.0 已发布状态；保留历史 Development 职责、两类 Requirement 和 MAS G0/G1 NOT_RUN |
| pilot → Development Build 设计 | 17 / 4 | 除中央元数据、固定链接和修订表外，§1～5 的输入、Package/Lock、Requirement、Verify 与 fixture 原文一致；没有把 Development 输出提升为可运行发布包 |
| responsibility audit → Evidence 职责设计 | 14 / 1 | 源标题及随后 229 行正文保留，新增中央元数据和修订表；Compiler/Host/Runtime/Owner 静态与执行责任边界一致 |

采用：单一 Go Core、冻结 v1alpha5 Artifact 与 Development v1alpha1、Development `NOT_ADMITTED`、静态 Descriptor 与运行时事实分离、精确 Schema closure、确定性 Build/Verify、Compiler 不执行 Runtime/Owner/Provider。排除：历史 MAS G0/G1 PASS、Host Admission、实际 Commit Proof/Reconcile、生产资格；源历史 CI 不计入本 Goal。

发现的明确差异：

1. 固定源和 [Compiler #61](https://github.com/odango-chan/ca-skill-compiler/issues/61) 当前仍以 `connectionagent.io/v1alpha5` 为 when 目标，并建议尽量复用旧接口；Next SR-013/EC02/SR-029 已把新目标改为 **1.6.0-only、无旧 DTO 兼容**。这是尚未由 Compiler Owner 闭合的设计差异，不是已发布契约。
2. 固定源 v2.1.0 是真实历史 Release，但 1.6.0 的 `languageTarget`、Artifact/BuildResult Schema、Package、Golden 均未发布。EC02 §5.1 的 `/2` 仅为候选，本报告不将其写成冻结 API。
3. 源工具链 §4 和 Evidence §6 保留当时“等待最终评审/未冻结”的历史文字，中央另加 v2.1.0 已发布说明。这是历史叙述并存，不应回写为新的产品状态。
4. 当前源仓默认分支是否可写、中央链接是否已进入 Next 默认分支不在本 Goal 授权范围；没有进行源仓链接替换或 `curl` 验收。
