## 1. 文档体系与目录原则

架构设计与设计说明书在 docs 下同级。总体架构只保留一份；详细机制进入设计说明书；文件结构、字段、协议和公共契约进入规范。治理、验收实施、参考审计各自独立，不再保留散落在 docs 根目录或英文目录中的第二份权威说明。

~~~text
docs/
├── 架构设计/
├── 设计说明书/
├── 规范/
├── 决策记录/          # 重大决策记录；当前没有单独 ADR
├── 治理/
├── 验收与实施/
└── 参考与审计/
~~~

README.md 是人工阅读入口；Agent.md 是自动化协作规则。两者不计入正式文档数量。

## 4. 推荐阅读路径

- 首次了解系统：README.md → 总体架构 → 本索引。
- 实现 Plugin：插件管理设计说明书 → 插件包与进程通信协议规范 → 演示验收基线。
- 实现 Skill 导入/选择：技能导入与选择设计说明书 → 技能与确定性保障格式规范 → 公共契约与所有权规范。
- 实现 Compiler/Python CEL 互操作：发布产物与 CEL 运行时互操作设计说明书 → 技能导入与选择设计说明书。
- 实现 Runtime：运行时与动作边界设计说明书 → 公共契约与所有权规范 → 演示验收基线。
- 接入 SBI 二进制：事件接入与二进制产物交接设计说明书 → 插件包与进程通信协议规范。
- 开始编码：Agent.md → 总体架构 → 对应设计说明书/规范 → 本次 SR → 验收基线 → 当前实现和测试。
- 发起独立评审：Agent.md review_scope → 文档编写与治理规范 → 本次 SR/Acceptance → CI 生成评审上下文（实施后）→ 统一评审提示词。 

## 5. 后续新增文档规则

新增文档前先判断现有文档是否能扩展。只有具备独立权威职责、独立消费者或独立验收边界时才新建文件。

每次新增、移动或废弃文档必须同步更新：

1. 本索引和文档数量。
2. 现有文档盘点与收敛计划。
3. README.md 导航（入口变化时）。
4. Agent.md 必读清单（协作规则或必读范围变化时）。
5. 受影响文档中的交叉链接。

不得增加第二份总体架构设计；不得把字段级规范复制进设计说明书；不得把历史审计材料当作当前规范源。
