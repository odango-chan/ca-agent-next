## 4. 阅读路径

- 首次了解架构：README.md → 总体架构 → 文档总目录。
- 实现 Plugin：Plugin 管理设计说明书 → Plugin 包与 IPC 规范 → Demo 验收基线。
- 实现 Skill 导入/选择：Skill 导入设计说明书 → SKILL 与 Assurance 格式规范 → 公共契约规范。
- 实现 Runtime：Runtime 与 Action Boundary 设计说明书 → 公共契约规范 → Demo 验收基线。
- 接入 SBI 二进制：事件接入与 Artifact Handoff 设计说明书 → Plugin 包与 IPC 规范。
- 开始编码：Agent.md → 总体架构 → 对应设计说明书/规范 → 验收基线 → 当前实现和测试。

## 5. 后续新增文档规则

新增文档前先判断现有文档是否能扩展。只有具备独立权威职责、独立消费者或独立验收边界时才新建文件。每次新增/移动/废弃必须同步更新：

1. 本索引。
2. 现有文档盘点与收敛计划。
3. README.md 的导航（仅在入口路径变化时）。
4. Agent.md 的必读清单（仅在协作规则或必读范围变化时）。

不得再增加第二份总体架构设计或散落的英文设计文档。
