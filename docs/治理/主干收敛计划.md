## 1. 目标与边界

目标是把恢复设计基线和仍有价值的开放设计/治理/实施增量整合为一个可独立评审的 Draft PR，最终只通过该统一 PR 进入 `main`。本计划不以分支数量或提交数量作为收编依据，逐项按文件差异、依赖关系和语义有效性决定。

保持以下架构不变量：

- CA-SL 仅采用 1.6.0，不兼容或迁移旧版。
- `when` 唯一位于 `assurance/contract.yaml`。
- Skill-facing Capability 与公开 Callable 双向一对一。
- 原版 3GPP OpenAPI 3.0 YAML 不修改、不投影；SBI JSON 与 NAS/NGAP 二进制 Codec 边界明确。
- Request Schema、Owner Contract、Provider Runtime Binding 的权责分离。
- Demo 排除项不扩张；未运行的产品 AC 保持 NOT_RUN/BLOCKED。
- 进入临时集成分支不等于进入 main；设计评审或 CI 不等于产品验收。
