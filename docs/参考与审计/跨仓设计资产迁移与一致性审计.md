## 2. 切换顺序

先在 Next 评审规范与设计。每份源文件处置需核对现行章节、重合设计、唯一路径引用、历史版本与生成依赖。目标文档合并并可访问后，按仓对重复正文改为精确章节链接；保留发布日志、机器契约、实现说明、操作说明、测试和部署。文档生成器依赖的输入在验证替代路径后再切换。未经确认的旧文档使用固定 SHA 引用，不扩大 Next Demo 范围。
