## 3. 架构一致性结论

总体判断：**PR #52 在"作者规范 / 语言规范 / 消费者（F02/F08/F09/Runtime/Plugin/Context/Importer/Studio）"主链上基本自洽**，Capability-first、`when` 迁入 SKILL.md Front Matter、共享资源根目录化、Host Resource Read / 统一 Script Runner、无 Skill Wait 等核心决策在增量文件内表达一致且可执行。

但**跨模块一致性不完整**：`when` 入口从 `contract.yaml` 迁到 `SKILL.md` Front Matter 这一本 PR 的核心变更，**没有同步到 Compiler 权威设计 EC02 与语言基线规范**。这两份文件仍明确要求 Compiler 读取 `assurance/contract.yaml` 的 `when`，并显式"不在 SKILL.md Front Matter 增加 when"，与增量文件正面冲突。这直接违反评审要求 §4.7"必须确认 Compiler 不会错误读取 Contract.when"。因此**尚不能判定为完整一致的设计**。

- 业务无关性：Agent Core 保持业务中立；Host Resource Read / Script Execution 以 Host-owned system Capability 承载，未把业务判断写入 Agent 核心 —— 符合。
- 契约来源：Skill 只引用 Capability，Capability↔Callable 双向一对一；3GPP 原版契约不投影 —— 符合。
- Skill/Tool、Compiler/Runtime 职责分离 —— 增量文件范围内符合；但 Compiler 实际读源位置与增量描述冲突（见 F-01）。

## 7. Finding 清单

### F-01（P0）Compiler 权威设计 EC02 仍要求读取 `assurance/contract.yaml` 的 `when`，与本 PR 核心变更正向冲突

- 对应 SR / IR：SR-032（AC-032-15、AC-032-12）；SR-013；F08；IR-008。
- 文件与行号：`docs/设计说明书/EC02-Compiler/Compiler设计说明书.md`（v0.2.19，**本 PR 未修改**）§1.5 L17、§2 表 L29、§3 标题 L39、§3.1 L43、**§3.1 L46**、§3.7 L137。
- 当前设计事实：
  - L43「唯一作者位置：`skills/<skill-name>/assurance/contract.yaml` 的可选顶层 when。」
  - L46「**不在 SKILL.md Front Matter 增加 when**；不创建 constraint.yaml、activation.yaml…」
  - L137「保留 `assurance/contract.yaml` 中 when 的原始 SourcePath、行、列…」
  - §1.5 L17、§2 L29 亦以 `Contract.when` 为 Artifact 输入。
- 与架构要求的冲突：CA-SL 1.6.0 §9 L385 明确 `when` 位于 SKILL.md Front Matter、不属于 `contract.yaml`；F08 §2 L29「`assurance/contract.yaml` 不包含 when」；F02 §7 L153、SR-013 §4、SR-032 AC-032-15 同此。F08 §2 L73 又把 Compiler 静态检查委托给 EC02 §3–7，形成**消费者与权威实现文档互相否定**。
- 实际影响：实现者若按 EC02 构建 Compiler，会从 `contract.yaml` 读取 `when` 且不支持 SKILL.md Front Matter —— 正是评审要求 §4.7 要排除的"Compiler 错误读取 Contract.when"。这使 SR-032 AC-032-15（Compiler 发布 CheckedExpr/DescriptorSet、Importer 与作者声明对账）无法成立，且违反"不允许实施者自行猜测"。
- 必须采取的修正：更新 EC02 §1.5 / §2 / §3（标题与 §3.1）/ §3.7，将 `when` 作者源改为"存在 Assurance 的 Skill 的 `SKILL.md` YAML Front Matter 扩展字段"，删除"不在 SKILL.md Front Matter 增加 when"，明确无 Assurance Skill 不声明 `when`、不进入 Compiler；`contract.yaml` 不再承载 `when`。
- 可验证的关闭条件：EC02 全文不再出现"contract.yaml.when / Contract.when 作为 Authoring 位置"，且 §3.1 明示 Front Matter 入口；与 CA-SL §9、F08 §2、SR-013 §4 逐句一致；评审复查可 grep 无残留。
