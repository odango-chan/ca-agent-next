## 1. 目标

恢复独立 Go OpenAMSM SBI Event/Delivery Plugin 的原始设计提案，并与 Next 唯一 Plugin Package/IPC 和 Host Artifact Handoff 契约逐项对齐。该 Plugin 只负责协议 ingress、规范化和 response delivery。

## 2. 原始材料与状态

已迁入 PR #1 的 docs/architecture.md 和 docs/acceptance.md。PR #1 为 OPEN / Draft / 未合并；main 当前只有 README，没有可运行实现。PR 文档不得写成当前 main 设计或实现。

## 3. 目标职责

- SBI HTTP/2 ingress 和 response Delivery。
- JSON、multipart/related、Content-ID 解析。
- 原始 N1/N2 字节按声明 slot 写入 Host inbound staging。
- 规范化 Event 和最小 NAS discriminator 提取。
- 按 Host delivery.dispatch 交付响应和输出 Artifact。
- 通过统一 IPC correlation、错误、cancel、shutdown 与 Host 交互。

明确不负责 Skill 选择、Run 创建、Tool/Owner 调用、PFCP、完整 NAS/NGAP 解码、业务状态或 Owner Receipt 判定。

## 4. 协议与分类门槛

- 使用 connectionagent.io/plugin-package/v1alpha1 和 connectionagent.io/plugin-ipc/v1alpha1。
- 不使用旧 ca-agent-host.plugin/v0，不保留兼容别名。
- CreateSMContext、UpdateSMContext、continuation 必须有明确 Event type 和 Schema。
- 对共享 UpdateSMContext，最小区分 0xC9 Modify 与 0xD1 UE-requested Release。
- malformed、unknown、unsupported discriminator 必须 fail closed。
- 0xD1 UE-requested Release 不得混同 AMF/network-initiated ReleaseSMContext。

## 5. 二进制边界

- 原始 N1/N2 不进入 NDJSON 或模型上下文，不用 Base64。
- Plugin 只提交相对 stagingPath、slot、mediaType、Content-ID、byteLength。
- Host 校验真实文件长度并导入 ArtifactStore，生成 opaque artifactRef。
- Tool Plugin 仅接收当前 Invocation 已授权的 artifactRef。
- Delivery 只读取当前 responseObligation 的 outbound staging 文件。
- 不增加 Plugin 数据库、独立 Artifact Service、额外 SHA-256 或 Codec Manager。
