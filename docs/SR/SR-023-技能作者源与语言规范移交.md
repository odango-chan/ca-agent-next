## 3. 规范基线与状态差异

- PR #88 规范刷新已 MERGED；PR #89 发布记录已 MERGED。
- 历史 v1alpha5 Release Record 的 languageTarget 固定为 `connectionagent.io/v1alpha5`；新链路唯一目标 CA-SL 1.6.0，机器标识由 Owner 后续冻结，不得沿用旧值。
