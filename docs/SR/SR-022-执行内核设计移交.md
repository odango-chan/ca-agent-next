## 3. 对照范围

逐项对照：
- Run/Procedure/Node lifecycle；
- Action/Provider invocation 与 binding；
- Predicate/Evidence/Observation source；
- Mutation outcome、Receipt、Reconcile；
- Pre-dispatch checks；
- Context/Artifact refs；
- Wait/Continuation；
- 既有 Admission 与 Next Demo 非目标边界。

必须把 Runtime 本身的权威结果、Owner 的业务事实和 Agent 的调用者知识分开。

## 4. Next 目标约束

Next 使用统一 Runtime Action Boundary，Deterministic Procedure 和 LLM-guided Action 共用同一调用边界。Wait 是目标 Node 声明的 READ trigger，不引入作者级 await/poll。Next Demo 不自动继承既有 ca-runtime 的生产 Admission、Trust、Deployment Qualification 或其他超出目标的机制。
