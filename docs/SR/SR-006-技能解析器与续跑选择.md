## 1. 目标

实现 Skill-first Resolver，保证新 Event 在模式选择和执行前绑定 Skill，continuation 精确恢复原 Run。

## 2. 实施范围

- 按规范顺序评估 when 候选。
- 单个显式候选直接选择；多个候选只在精确集合内消歧。
- 新 Event 先检查各候选声明的 Request Schema；校验不通过时诊断并排除。无显式候选时，从无 when 且符合资格的 Skill 中语义选择。
- when=false/error 的 Skill 排除；无候选时澄清或拒绝。
- continuation 优先恢复原 Run、Skill 和 generation，不重新选择。

## 3. 非目标

- 不增加 Event→Skill 表、Event→Mode 表或 Generic Agent 无绑定回退。
- 不把 when false/error 的 Skill 放回语义候选。
