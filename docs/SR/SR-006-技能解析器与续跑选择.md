## 1. 目标

实现 Skill-first Resolver，保证新 Event 在模式选择和执行前绑定 Skill，continuation 精确恢复原 Run。

## 2. 实施范围

- 按规范顺序评估 when 候选。
- 单个显式候选直接选择；多个候选只在精确集合内消歧。
- 无显式候选时，仅对没有 when 的 Skill 进行 SKILL.md 语义选择。
- when=false/error 的 Skill 排除；无候选时澄清或拒绝。
- continuation 优先恢复原 Run、Skill 和 generation，不重新选择。

## 3. 非目标

- 不增加 Event→Skill 表、Event→Mode 表或 Generic Agent 无绑定回退。
- 不把 when false/error 的 Skill 放回语义候选。

## 4. 依赖与前置条件

SR-005。

进入 READY 前必须确认所有前置 SR 已 VERIFIED，或在 SR 中明确记录并批准并行实施理由；外部依赖必须有可核对的版本、接口和可用证据。

## 5. 验收条件

1. 一个 when=true 候选直接绑定。
2. 多个 when=true 候选只在精确集合内消歧并校验 Skill ID。
3. 无 when 候选可进入语义选择；false/error 候选不可进入。
4. 无候选时明确澄清/拒绝，不启动无绑定 Agent。
5. continuation 恢复原 Run 和 generation，不重新选择 Skill。

验收时必须引用演示验收基线中的对应 Acceptance ID，并记录真实执行命令、测试结果、Example 和覆盖范围。未执行项保持 NOT_RUN。
