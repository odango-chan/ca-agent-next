## 1. 目标仓与基线

`odango-chan/ca-client-tools`，`main`，`7bcb2614aa3615d8358df31eecefd0909e894e40`。Provider v2 与 Next 的统一 IPC 存在消费适配差异；#39 是独立 Codec 候选证据。MAS Owner v1alpha4 契约源位于 `contracts/owner/openamsm-mas/v1alpha4`，当前由 Owner source manifest / ToolCatalog 发布，不是 Compiler v2.1.0 可直接消费的正式 Interface Package。已发布 `ca-client-tools_interface_1.1.0.zip` 是单独 READ Interface Package，不得替代 MAS Owner root。

## 2. 实施范围

- 比对 Provider v2、Tool Interface、Binding 与已发布 Codec 契约，保留工具运行说明；覆盖既有调用和 Next 单管理器适配。
- 由 Owner/Publisher 从固定的 MAS Owner v1alpha4 契约源发布正式 `connectionagent.io/interface-package/v1alpha1`，供 Skill Contract root `mas: urn:openamsm:mas:tool-contracts` 导入。
- 正式包身份固定为 `packageId=urn:openamsm:mas:tool-contracts`、`version=v1alpha4`、`publisher=openamsm.smf.mas`、`languageTarget=connectionagent.io/v1alpha5`。来源固定为 `odango-chan/ca-client-tools@v1.2.0`，路径 `contracts/owner/openamsm-mas/v1alpha4`，resolved Revision `fc44c3a745c68443fcfb12054c7eadf0ed7cc3f7`，Owner source build identity `sha256:ac834080f31ff0fa91b9eb846fa47c889a94837fc1f37ec2034190e4e83085c0`。
- 正式 `package.json` 严格遵循 Compiler v2.1.0 `contracts/development/v1alpha1/interface-package.schema.json`。它是新生成的 Interface Package envelope；原 `manifest.json` 仍是 `connectionagent.io/toolcatalog/v1alpha4` Owner source manifest，不可直接改名或冒充 `package.json`。
- Export 规则：每个公开 ToolCatalog contract ID 对应一个 `CallableCatalog` export，路径 `tool-catalog.yaml`；每个 Capability ID 对应一个 `CapabilityCatalog` export，路径 `capability-contracts.yaml`；每个 Evidence fact ID 对应一个 `EvidenceDescriptor` export，路径 `evidence-guarantees.yaml`；公开 Callable/Capability/Evidence 的 Schema 引用闭包中每个精确 Schema `$id` 对应一个 `Schema` export。
- 对纳入包的公开源文件保持原始字节，不重新序列化 YAML/JSON。先按 Owner source `manifest.json` 校验源文件；正式 `package.json.files[]` 再对实际包内文件计算 SHA-256。
- 不导出 `deployment-binding.yaml`、部署私有配置或 Runtime-only Provider bindings；`deployment-binding.schema.json` 仅在它确实进入公开接口引用闭包时才可纳入，否则排除。不得将 ca-client-tools#37 的 private Runtime-only bindings 转成 public Callable。
- 该包只提供静态接口描述，不包含 Owner Trust、Deployment Grant、Provider binding 或 Runtime Admission。Compiler Development Build 的 `publisher` 字段是声明身份，不是信任证明。

## 3. 依赖与启动条件

- 依赖 Compiler v2.1.0 冻结 Interface Package schema、F09 §4.5 和 Studio #269 的 BuildRequest/Import 集成。
- Publisher 必须从上述固定 source Revision 生成包，并保留 Package ID、版本、Owner publisher 与原始公开接口字节；不得由 Studio 包装当前 `tool-catalog` lock entry。
- 导出闭包必须完整满足 ToolCatalog 的 input/output Schema、Capability、EvidenceDescriptor、Receipt/Commit Proof 等实际引用；缺失或歧义引用必须在发布前失败。
