## 3. 设计要求

1. Tool Interface Package 是 Callable ID、Input/Output Schema、Effect、Capability、Artifact IO 和 Owner Outcome 的唯一权威来源。
2. Provider v2 负责实际 Provider 进程/Backend binding；Next Plugin Manager 负责 Plugin Package/IPC。适配器只能做协议映射，不改变 Callable 语义。
3. 一个 Plugin Manager；Tool 是 tools Extension 中的 Operation；不得建立 Provider Manager、Tool Registry 或 Codec Manager。
4. Tool 调用必须先经 Runtime Action Boundary 校验 Skill Scope、Schema、Run、Effect 和 Artifact refs。
5. Owner Receipt、Commit Proof、UNKNOWN 和 Reconcile 由 Owner/Interface Package 定义，Provider 不得自行推断提交。
6. Codec 是普通 Tool Callable；原始二进制由 Host ArtifactStore 持有，Codec 只按需返回结构化投影或新 Artifact。
7. 不复制 Owner 的 MAS 业务实现，不在 Provider 内硬编码 Skill/Agent 业务路由。
