## 5. 核心设计决议

1. Tool 是 Plugin 导出的 Callable Operation，不是独立进程、Manager 或 Registry。
2. Tool Interface Package 拥有公开 Callable ID、Capability membership、输入/输出 Schema 和 Effect。
3. Owner Contract Package 拥有 Owner Callable、Owner Outcomes、Receipt、Commit Proof 和 Reconcile 语义。
4. Provider Runtime Bindings 是私有执行 sidecar，映射 runtime/owner callable 到 backendOperationId，并声明 HostInvocation、privateArguments、observation/receipt 定位；它不授权 Skill，也不重定义 Owner。
5. ca-client-tools v1.2.0 的 Provider v2 由唯一 Plugin Manager 内部 ProviderV2 Tools Extension Driver 适配；Native Plugin 继续使用 Plugin IPC v1alpha1。
6. Runtime 在 dispatch 前检查当前 Skill 的精确 Callable/Capability Scope、Schema、Effect 和 Artifact 来源；Plugin Manager 不做授权。
7. Provider/HTTP/IPC 成功不等于 COMMITTED；只有 Owner Receipt 与 Commit Proof 精确绑定原 Invocation 才能产生 COMMITTED。UNKNOWN 保持 UNKNOWN，并按原 Invocation Reconcile，不重发 mutation。
8. Codec 不单独建 Plugin/Manager；只在正式发布 Callable/Runtime Binding 后作为现有 Tools Extension 的 Operation 使用。
